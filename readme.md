`ID` 14

`Title` Добавление задачи в пустом проекте и удаление через контекстное меню

`Title autotest` add_task_project_case4_test.py

`Type` Позитивный

> Preconditions

Проект "Autotest project" без задач 

> Шаги воспроизведения

1. Зайти в приложение
2. Перейти в проект "Autotest project"
3. В гриде задач нажать на кнопку "Добавить задачу"
4. Ввести название -> "/Текущая дата формата - ДД,ММ,ГГ/"
5. Ожидать отображение задачи
6. Вызвать контекстное меню у задачи
7. Нажать кнопку удалить
8. Подтвердить удаление
9. Проверить отсутствие задач в проекте 

> Ожидаемый результат

Задача в проекте добавляется, а после добавления, через контекстное меню происходит удаление

> Post conditions

Постусловий нет
